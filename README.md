## The entry

> **Chief Apologizer for Haunted Vending Machines**

Forty-five characters. A sober corporate title — Chief Apologizer — bolted
onto a job nobody has ever held: saying sorry on behalf of vending machines
that are haunted. It reads like a real posting from a facilities department
that has given up, and you can picture the person immediately: clipboard in
hand, standing in a dim break room at 2 a.m., apologizing to a machine that
just ate someone's coins and whispered back.

## How it works

`main.ts` (Node 22, standard library only) writes the title above to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The text is
embedded in the program itself — no other files are read, no network, no
clock — so the run is deterministic from any working directory.

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
